# CATI · PRO

测测你是哪只小猫(￣﹃￣)

24 道题，大半是恋爱里的小场景（暧昧期没回消息、吃醋、冷战、前任突然出现……），中间穿插你自己的时刻（凌晨两点、下雨的周末、过年被亲戚问有没有对象……），测出你是 16 只小猫里的哪一只，再把链接发给 ta，让 ta 先猜。题目里全用「ta」，不分性别。版式、动画和文案语气照着原版 cati 来。

- **四个维度**：贴贴 / 独立、敏感 / 钝感、直球 / 嘴硬、心动 / 心安，组合出 16 只猫，外加 2 只隐藏款。
- **可以选两个**：大部分题最多选 2 个；有两道题用「3 颗小鱼干」分配；吃醋那题拆成「心里」「嘴上」两问；几道题的答案凑在一起，会拼出更准的句子。
- **结果**：主猫 + 成分表 + 性格四维 + 按你的答案拼出的几句话 + 最佳配对小猫、最佳友伴小猫。
- **先猜再看**：分享链接打开后，ta 先从 16 只猫里猜，再揭晓；猜错哪个维度，就给一句具体的话，比如「ta 说的『没事』，你都当真了吧」。
- **猫猫 CP 卡和图鉴**：ta 测完自动出两只猫的 CP 卡；测过、猜过的猫都会在图鉴里点亮。
- **彩蛋**：最后一题选「汪！」是隐藏款「卧底小狗」；四个维度都接近五五开是「薛定谔的猫」。
- **分享图**：点击后可选「让 ta 猜猜」或「晒出我的结果」。猜猜版用统一问号猫，扫码先猜再揭晓；结果版展示真实猫型，扫码直接看完整结果。两种都是 1080×1440 竖图，长按保存。

## 改题、改文案

所有内容都在 `js/data.js`：猫的名字、称号、文案，题目和每个选项往哪个维度推多少。改完直接刷新页面就能看到。
每个选项的 `e` 写成 `{ A: 1, C: -0.5 }` 这样：A 贴贴(+)/独立(-)，B 敏感(+)/钝感(-)，C 直球(+)/嘴硬(-)，D 心动(+)/心安(-)。改完可以跑一下 `node tools/sim.js`，看看 16 只猫出现得匀不匀、隐藏款够不够稀有。

## 文件

| 文件 | 内容 |
| --- | --- |
| `index.html` | 页面结构和样式 |
| `js/data.js` | 题目、猫、文案 |
| `js/engine.js` | 算分、成分表、CP 卡、猜猜看、分享链接的编码 |
| `js/art.js` | 18 只猫的扁平剪影画像（跟原版黑猫一个画法） |
| `js/badcat.js` | 封面和答题页那只推杯子的黑猫动画，照搬自原版 cati |
| `js/lottie.js` | 播放动画用的 lottie-web 5.12.2（MIT） |
| `js/app.js` | 页面交互、结果图 |
| `js/qrcode.js` | 二维码库 qrcode-generator（MIT，作者 Kazuhiko Arase） |
| `tools/sim.js` | 模拟几万人作答，检查各只猫的比例（只在改题时用，不用部署） |

纯静态页面，没有后端，也不收集任何数据；作答和结果保存在本机，主动分享时结果快照放在链接中。

分享链接使用 `#r3-…` 保存结果快照：四维分数、隐藏款、三句个性描述和成分表参数，不包含逐题答案。分数存成「分子_分母」两个整数（题目推力只有 1、0.5、0.4，原始分 ×60 一定是整数），还原出来和本人看到的完全一样；三句话只存编号（`COMBOS` 里第几句、哪道题的哪个选项）。这样分享链接和二维码明显缩小：已验证的一份结果从 393 字符缩到 77 字符，二维码从 77×77 格缩到 37×37 格。样例海报缩至 360px 宽并压成 JPEG 后仍能识别，实际识别效果也取决于转发压缩和扫码环境。链接里只有数字和编号，看不出猫型；这不是加密，拿到链接的人能算出结果。

因为句子按编号存，`COMBOS` 新句子请加在末尾、不要调顺序，题号也别改，否则旧链接会对上别的句子；修改编号对应的文案时，旧链接也会展示更新后的文案；这就是当前设计。某个编号不再存在的话，旧链接会跳过那一句。

上一版的 `#r2-…`（链接很长）和更早的 `#g-…` 链接仍可打开；`#g-…` 丢掉的精度和个性描述无法恢复，页面会提示重新分享。可运行 `node --test tools/share.test.js` 验证新链接无损往返、长度和旧链接兼容。

结果版分享图和 CP 卡在快照后加 `/result` 展示标记，打开时直接揭晓；普通分享链接和猜猜版分享图仍先猜。展示标记不改变快照内容。页面与海报不再显示四字维度缩写，结果页保留完整中文维度图表。

## 本地打开

直接双击 `index.html` 就能测。「分享给朋友」生成的链接指向页面当前的地址，所以要发给别人，得先把页面放到网上。

## 部署

把这些文件放进仓库根目录，Settings → Pages → Source 选 `Deploy from a branch`，分支选 `main`、目录选 `/ (root)`，保存后等一两分钟，就能在 `https://<你的用户名>.github.io/cati/` 打开。

黑猫动画来自原版 cati（exoticflicker/cati），原仓库没有开源许可证。金渐层、银渐层的文案，还有布偶、奶牛猫、狸花、缅因、蓝猫里的几句，也是从原版改编的。自己玩没问题；要公开发布的话，先问原作者，或者把 `js/badcat.js` 换成自己的动画、把这几段文案换成自己写的。
